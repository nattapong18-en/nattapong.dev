ผมจดโดเมน `nattapong.dev` ไว้นานแล้ว แต่ยังคิดไม่ออกว่าจะเอาไปทำอะไร ตอนนี้เรียนวิศวกรรมคอมพิวเตอร์ปี 4 ทำโปรเจกต์ไว้ใน GitHub พอสมควร แต่ยังไม่มีที่ไหนรวมทั้งหมดไว้ให้คนอื่นดูได้ง่าย เลยตัดสินใจทำเว็บนี้ขึ้นมา

## เว็บนี้มีไว้ทำอะไร

- **รวมผลงาน**: โปรเจกต์ที่ทำมา ตั้งแต่ Rust API, ESP32 ไปจนถึงเว็บที่ใช้ TensorFlow.js
- **รับงาน**: รับทำเว็บ ระบบเล็กๆ และงาน IoT ระหว่างเรียน
- **Blog**: จดสิ่งที่เรียนรู้ และบันทึกการเริ่มทำ open source

## Stack ที่ใช้

- [Astro](https://astro.build): เขียนเนื้อหาเป็น Markdown ได้ และหน้าเว็บส่งออกมาเป็น HTML ล้วน โหลดเร็ว
- [Tailwind CSS](https://tailwindcss.com): จัดหน้าได้เร็ว และรองรับ dark mode ง่าย
- **Cloudflare Pages**: push ขึ้น GitHub แล้วเว็บ deploy เอง ใช้ฟรี

ข้อมูลทุกอย่างบนหน้าแรกเก็บไว้ในไฟล์เดียวคือ `src/data/site.ts` ส่วนบทความเป็นไฟล์ `.md` อยู่ใน `src/content/blog/`

## ต่อจากนี้

โค้ดของเว็บนี้เปิดเป็น open source อยู่ที่ [GitHub](https://github.com/nattapong18-en/nattapong.dev) ถือเป็น repo แรกที่ตั้งใจทำให้คนอื่นเข้ามาดูได้ ต่อไปจะเขียนเล่าโปรเจกต์แต่ละตัวละเอียดขึ้น และบันทึกการ contribute open source ไว้ที่นี่ครับ
