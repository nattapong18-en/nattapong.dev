# nattapong.dev

เว็บไซต์ส่วนตัวและ portfolio ของ Nattapong — [nattapong.dev](https://nattapong.dev)

สร้างด้วย [Astro](https://astro.build) + [Tailwind CSS](https://tailwindcss.com) และ deploy บน Cloudflare Pages

## เริ่มใช้งาน

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # output อยู่ที่ dist/
```

ข้อมูลส่วนตัว บริการ และโปรเจกต์ทั้งหมดแก้ได้ที่ `src/data/site.ts`
